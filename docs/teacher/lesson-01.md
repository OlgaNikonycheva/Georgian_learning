### Plural (множественное число)

Noun + **ები**

If the noun ends in **ა** or **ი**: drop **ა** / **ი**, then add **ები**.

Teacher examples:

- გოგოები — Девочки
- ბიჭი − ი → **ბიჭები** — Мальчики
- და − ა → **დები** — Сестры
- კალმები — Ручки
- ფანქრები — Карандаши

### Preposition «в»: **-ში**

Noun + ending **ში**

If the noun ends in **ი**: drop **ი**, then add **ში**.

Teacher examples:

- მაგიდა +ში = **მაგიდაში** — В столе
- წიგნი მაგიდაში არის — Книга в столе
- სკამი − ი → სკამ +ში = **სკამში** — В стуле

### Preposition «на»: **-ზე**

Noun + ending **ზე**

If the noun ends in **ი**: drop **ი**, then add **ზე**.

Teacher examples:

- მაგიდა +ზე = **მაგიდაზე** — На столе
- წიგნი მაგიდაზე არის — Книга на столе
- სკამი − ი → სკამ +ზე = **სკამზე** — На стуле
