## Grammar

### To be in present tense

Named in the lesson. Full paradigm not given.

Example from the teacher:

- წიგნი მაგიდაზე არის

### Plural (множественное число)

Noun + **ები**

If the noun ends in **ა** or **ი**: drop **ა** / **ი**, then add **ები**.

Teacher examples:

- გოგოები — Девочки
- ბიჭი − ი → **ბიჭები** — Мальчики
- და − ა → **დები** — Сестры
- კალმები — Ручки
- ფანქრები — Карандаши

### Preposition «в»: **-ში**

Noun + ending **ში**

If the noun ends in **ი**: drop **ი**, then add **ში**.

Teacher examples:

- მაგიდა +ში = **მაგიდაში** — В столе
- წიგნი მაგიდაში არის — Книга в столе
- სკამი − ი → სკამ +ში = **სკამში** — В стуле

### Preposition «на»: **-ზე**

Noun + ending **ზე**

If the noun ends in **ი**: drop **ი**, then add **ზე**.

Teacher examples:

- მაგიდა +ზე = **მაგიდაზე** — На столе
- წიგნი მაგიდაზე არის — Книга на столе
- სკამი − ი → სკამ +ზე = **სკამზე** — На стуле

## Time forms (from vocabulary)

**«В [день недели]»:** add **ს**

If the word ends in **ი**: drop **ი**, then add **ს**.

Teacher examples:

- ორშაბათი − ი → ორშაბათ +ს = **ორშაბათს** — В понедельник
- კვირა +ს = **კვირას** — В воскресенье

**«до»:** **-მდე**

- **ორშაბათამდე** — до понедельника

## Grammar — «у кого-то есть / было / будет» with a noun

Noun + **ს** + the have-verb (the same pattern as **მას**).

| Example | How the teacher built it |
| --- | --- |
| დედას აქვს / ჰყავს | У мамы есть: დედა + ს |
| ბიჭს ჰქონდა / ჰყავდა | У мальчика была: ბიჭი − ი + ს |
| დებს აქვთ / ჰყავთ | У сестер есть: დები − ი + ს |

If the noun ends in **ი**, drop **ი**, then add **ს**. Same in the plural: **დები** → **დებს**.
