## Grammar

### To be in present tense

Example from the teacher:

- წიგნი მაგიდაზე არის

### Plural (множественное число)

Noun + **ები**

If the noun ends in **ა** or **ი**: drop **ა** / **ი**, then add **ები**.

Teacher examples:

- გოგოები — Девочки
- ბიჭი − ი → **ბიჭები** — Мальчики
- და − ა → **დები** — Сестры
- კალმები — Ручки
- ფანქრები — Карандаши

### Preposition «в»: **-ში**

Noun + ending **ში**

If the noun ends in **ი**: drop **ი**, then add **ში**.

Teacher examples:

- მაგიდა +ში = **მაგიდაში** — В столе
- წიგნი მაგიდაში არის — Книга в столе
- სკამი − ი → სკამ +ში = **სკამში** — В стуле

### Preposition «на»: **-ზე**

Noun + ending **ზე**

If the noun ends in **ი**: drop **ი**, then add **ზე**.

Teacher examples:

- მაგიდა +ზე = **მაგიდაზე** — На столе
- წიგნი მაგიდაზე არის — Книга на столе
- სკამი − ი → სკამ +ზე = **სკამზე** — На стуле

## Time forms (from vocabulary)

**«В [день недели]»:** add **ს**

If the word ends in **ი**: drop **ი**, then add **ს**.

Teacher examples:

- ორშაბათი − ი → ორშაბათ +ს = **ორშაბათს** — В понедельник
- კვირა +ს = **კვირას** — В воскресенье

**«до»:** **-მდე**

- **ორშაბათამდე** — до понедельника

## Notes vs regular Georgian

Teacher forms kept. Short flags only:

- **თქვენ გიდიოდით** (exit room imperfect) — usual 2pl is **გადიოდით**.
- **თქვენ შევდიოდით** (enter room imperfect) — usual 2pl is **შედიოდით**.
- **თქვენ ავდიოდით** (enter transport / up imperfect) — usual 2pl is **ადიოდით**.
- **სარეცხი გუბკა** — **გუბკა** is a Russian loan (губка); usual sponge is **ღრუბელი** (also filed here).
- **ქაცვი** glossed sea buckthorn — usual dictionary word is **კოწახური**.
- **კონდიციონერი** glossed conditioner — usual **კონდიციონერი** is also (often) air conditioner.
- **ღრუბელი** glossed sponge (also cloud/cloud) — usual **ღრუბელი** is cloud; the same word is used for a sponge.
