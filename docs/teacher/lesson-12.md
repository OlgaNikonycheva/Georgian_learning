## Grammar — future «need»

**და** + present need.

| Georgian | Teacher gloss |
| --- | --- |
| მე დამჭირდება | Мне будет нужно |
| შენ დაგჭირდება | Тебе будет нужно |
| მას დასჭირდება | Ему / ей будет нужно |
| ჩვენ დაგვჭირდება | Нам будет нужно |
| თქვენ დაგჭირდებათ | Вам будет нужно |
| მათ დასჭირდებათ | Им будет нужно |

## Grammar — future «want»

**მო** + **მინდ** + person ending + **ება**.

| Georgian | Teacher gloss |
| --- | --- |
| მე მომინდება | Я захочу |
| შენ მოგინდება | Ты захочешь |
| მას მოუნდება | Он / она захочет |
| ჩვენ მოგვინდება | Мы захотим |
| თქვენ მოგინდებათ | Вы захотите |
| მათ მოუნდებათ | Они захотят |

## Grammar — «для»: **-თვის**

Noun + **სთვის**.

Teacher example:

- დედა + სთვის = **დედასთვის** — Для мамы

Possessive pronouns: drop the last **ი**, then add **თვის**.

| Georgian | Teacher gloss |
| --- | --- |
| ჩემთვის | Для меня |
| შენთვის | Для тебя |
| მისთვის | Для него / нее |
| ჩვენთვის | Для нас |
| თქვენთვის | Для вас |
| მათთვის | Для них |
