## Grammar — want

Teacher rule for past: present form + ending **ოდა**.

### Present — **ინდა**

| Georgian | Teacher gloss |
| --- | --- |
| მე მინდა | Я хочу |
| შენ გინდა | Ты хочешь |
| მას უნდა | Он / она хочет |
| ჩვენ გვინდა | Мы хотим |
| თქვენ გინდათ | Вы хотите |
| მათ უნდათ | Они хотят |

### Past — **ინდოდა**
